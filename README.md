# FileVault - 多端文件同步系统

一个轻量级的本地文件备份和分享工具，支持局域网内多设备同步。

## 功能特点

- 📁 **文件管理** - 支持上传、下载、删除文件
- 📂 **文件夹管理** - 新建文件夹、重命名、删除文件夹
- 🖱️ **拖拽归类** - 拖拽文件到文件夹进行归类
- 🗑️ **批量删除** - 多选文件一键删除
- 🔄 **多端同步** - 局域网内设备实时同步
- 📱 **二维码分享** - 扫码即可下载文件
- 🖼️ **图片预览** - 支持图片在线预览
- 📊 **分类筛选** - 按类型和时间筛选文件
- 📋 **列表/卡片视图** - 自动切换显示模式
- 💾 **数据持久化** - 文件永久保存，重启不丢失
- ⚡ **开机自启动** - 支持Windows开机自动运行

## 快速开始

### 方式一：一键启动（推荐）

双击 `start.bat` 文件，系统会自动：
1. 启动服务器
2. 打开浏览器访问 http://localhost:8888

### 方式二：创建桌面快捷方式

1. 双击 `create_shortcut.bat` 创建桌面快捷方式
2. 以后双击桌面上的 "FileVault" 图标即可启动

### 方式三：命令行启动

```bash
node server.js
```

然后在浏览器打开 http://localhost:8888

### 访问地址

- 本地: http://localhost:8888
- 局域网: http://你的IP:8888

## 数据存储

- 文件存储在 `data/` 目录
- 元数据保存在 `data/metadata.json`
- 文件夹数据保存在 `data/folders.json`
- 每次启动会自动加载之前上传的文件

## 公网访问

如果需要在外网访问，请参考 [内网穿透指南](docs/内网穿透指南.md)

推荐使用 Cloudflare Tunnel：
```bash
cloudflared tunnel --url http://localhost:8888
```

## 技术栈

- Node.js (后端服务器)
- 原生 HTML/CSS/JavaScript (前端)

## 使用说明

1. 启动服务器后，浏览器会自动打开
2. 拖拽文件到上传区域或点击"选择文件"上传
3. 点击文件的"分享"按钮生成二维码
4. 手机扫描二维码即可下载文件
5. 文件会永久保存，下次打开仍然可见

### 文件夹管理

1. 点击"新建文件夹"按钮创建文件夹
2. 点击文件夹进入查看内部文件
3. 拖拽文件到文件夹上进行归类
4. 点击"重命名"修改文件夹名称
5. 点击"删除"删除文件夹及其所有文件

### 批量删除文件

1. 点击文件列表上方的"选择"按钮进入选择模式
2. 点击文件卡片或列表项选中要删除的文件
3. 点击"全选"可选中当前筛选的所有文件
4. 点击"删除选中"批量删除选中的文件
5. 点击"取消"退出选择模式

### 开机自启动

- 双击 `install_autostart.bat` 安装开机自启动
- 下次开机时，服务器会自动启动，浏览器会自动打开
- 双击 `uninstall_autostart.bat` 取消开机自启动

## 重要提示

⚠️ **请勿直接双击 index.html 文件打开**

直接打开本地 HTML 文件无法连接服务器。正确的方式是：
1. 双击 `start.bat` 启动服务器
2. 或通过浏览器访问 http://localhost:8888

## 配置

- 端口：默认 8888，可在 server.js 中修改 `CONFIG.PORT`
- 文件大小限制：默认 100MB，可在 server.js 中修改 `CONFIG.MAX_FILE_SIZE`
