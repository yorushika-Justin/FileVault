# FileVault 内网穿透配置指南

## 方案一：Cloudflare Tunnel（推荐）

### 步骤：

1. **下载 cloudflared**
   - 访问：https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
   - 下载 Windows 版本

2. **运行穿透命令**
   ```bash
   cloudflared tunnel --url http://localhost:8888
   ```

3. **获取公网网址**
   - 命令运行后会显示类似 `https://xxx-xxx.trycloudflare.com` 的网址
   - 这个网址可以在任何设备上访问

---

## 方案二：ngrok

### 步骤：

1. **注册账号**
   - 访问：https://ngrok.com/
   - 注册并获取 authtoken

2. **下载并配置**
   ```bash
   ngrok config add-authtoken 你的token
   ```

3. **启动穿透**
   ```bash
   ngrok http 8888
   ```

4. **获取公网网址**
   - 会显示类似 `https://xxx.ngrok.io` 的网址

---

## 方案三：购买云服务器

如果你需要永久稳定的网址：

1. 购买云服务器（阿里云、腾讯云等）
2. 购买域名
3. 部署 FileVault 项目
4. 配置域名解析

---

## 注意事项

- 免费的内网穿透服务每次启动会生成新的网址
- 如果需要固定网址，建议购买云服务器和域名
- 手机端访问时确保手机和电脑在同一局域网，或使用公网穿透
